# 安全策略

## 支持范围

仅支持最新正式发布版本。由于 Clash for Windows 已停止维护，本项目无法承诺修复其 Electron 运行环境或第三方依赖继承的所有漏洞。

## 安全问题报告

疑似安全问题请优先使用私密渠道报告，并提供：

- 受影响版本；
- Windows 版本；
- 最小复现步骤；
- 已脱敏日志；
- 预期影响。

不要提交订阅 URL、API Token、节点密码、私钥、Cookie、服务令牌或完整用户配置。

## 信任模型

安装器和更新器需要管理员权限。用户应核对发布来源、Release SHA-256、脚本内容和 UAC 中显示的路径。

项目应为每个 Release 提供：

- 压缩包 SHA-256；
- 文件级 `SHA256SUMS.txt`；
- 安装器和更新器源码；
- 提权辅助程序和服务辅助程序源码；
- 非官方声明和脚本行为说明。

## 不接受的报告

- 仅因杀毒软件对未签名自编译辅助程序产生通用启发式告警，而无实际恶意行为证据；
- 包含未经脱敏的个人配置或第三方账号凭据；
- 针对上游原版且与本项目修改无关的问题。
