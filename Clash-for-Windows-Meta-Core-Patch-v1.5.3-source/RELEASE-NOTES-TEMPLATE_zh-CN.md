# Clash for Windows Meta Core Patch v1.5.3 更新说明

## 版本定位

这是基于 Clash for Windows 0.20.39 修改的非官方 Windows x64 版本。该版本整理了经过实机验证的核心替换、服务模式、TUN/TAP、混合配置和核心更新逻辑，移除了仅用于开发测试的固定版本降级脚本。

## 本次更新内容

- 将旧 Clash 核心替换为现代 Meta 核心，并保留原有 Clash for Windows 界面和配置习惯。
- 支持本地模式、系统代理、服务模式、TUN 模式和 TAP 虚拟网卡模式。
- 修复 Clash for Windows 客户端内安装、卸载服务模式和虚拟网卡时的 UAC 提权兼容问题。
- 保留 YAML 和 JavaScript 混合配置功能。
- 改进现代订阅配置与 AnyTLS 节点兼容性。
- 将停止维护的 Clash for Windows 应用更新入口改为核心检查和一键更新。
- 增加软件内更新进度窗口，显示检查、下载、校验、备份、替换、重启和回滚状态。
- 更新前验证 SHA-256、核心版本和当前配置，避免下载错误或不兼容核心后直接覆盖。
- 同步更新本地模式核心和服务模式受保护核心。
- 更新失败时自动恢复上一个可用核心和服务配置。
- 增加 `restore.cmd` 和 `diagnose.cmd`。
- 移除 1.19.28/1.19.29 固定版本测试、降级和开发验证入口。

## 安装脚本操作概要

安装脚本大致会执行以下操作：

1. 检查 Clash for Windows 安装目录；
2. 请求管理员权限；
3. 停止 Clash for Windows、旧核心和旧服务；
4. 备份原始程序运行文件、核心和服务辅助程序；
5. 安装修改后的 Electron 运行文件；
6. 从官方 GitHub Release 下载并校验核心；
7. 部署本地核心和服务模式受保护核心；
8. 生成本机服务认证令牌并设置文件 ACL；
9. 清理冲突的旧服务/同名旧计划任务，安装新的 Windows 服务；
10. 写入日志并验证服务是否正常响应。

脚本不会上传配置和订阅，不会关闭系统安全软件，不会安装根证书，不会开放公网远程管理接口，也不会捆绑第三方软件。更完整的说明见 `SECURITY-TRANSPARENCY.md`。

## 安装与升级

- 从旧补丁升级前，请从系统托盘完全退出 Clash for Windows。
- 将本版本解压到全新目录后运行 `install.cmd`。
- 安装器会保留首次生成的原始备份；不要手工删除备份文件。
- 安装完成后，服务模式应显示为已安装；TUN 与 TAP 不建议同时启用。

## 还原

运行 `restore.cmd` 会移除补丁服务和受保护核心，并在备份存在时恢复原始运行文件、核心和服务辅助程序。用户订阅、配置文件和规则不会被删除。

## 已知限制

- 仅面向 Windows x64 和 Clash for Windows 0.20.39。
- Clash for Windows 已停止维护，本项目无法消除其旧 Electron 运行环境继承的全部风险。
- 不同 Windows 精简版、安全软件和企业策略可能影响 UAC、服务或虚拟网卡安装。
- 核心下载和更新依赖 GitHub Release 可访问。

## 发布文件核验

下载后请核对 Release 页面提供的 SHA-256。不要从来历不明的网盘、群文件或二次打包站点获取管理员权限安装包。
